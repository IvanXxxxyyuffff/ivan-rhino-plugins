## 3. 功能现状

### 表面条纹
- **曲面面改走「等值线带」**（2026-09-30 第五批）：多面 + 曲面面时，条纹 = 曲面与一族平行平面的交带
  （`|(p-A)·n3d - k·pitch| <= w/2`，n3d = 参考平面法向 × 全局条纹方向，**对同一对象所有面一致** → 接缝两侧逐点相等）。
  实现：在共享参考平面的 2D 里铺栅格（h = max(w/4, 对角/900)）算 phi → marching squares 提闭合环 → 现有 `MakeOutlineCurve` 出真曲线；
  边距只对非顺接边界生效。单面/平面/垂直回退路径一字未动（用例3 圆柱、用例8 共面都走老路径）。
  子代理另做了离线内核校验（独立控制台 + 解析场）：竖直/斜向/弯曲/带孔/带边距/浅角 6 组全过，带宽偏差 0、弯曲场超出 ≤h²/(8R)。
- **多面 + 曲面时边距/接缝改在 3D 里量**（2026-09-30 第四批）：曲面片投影到共享平面会自相交，2D 距离判定会把大部分条纹误杀（实测 200mm 的壳上只出 7 条，应有 ~50 条）→ 多面且本面非平面时，把 2D 参数映射回 3D、直接量到边界曲线的 3D 距离；单面/平面路径完全不变。
- **多面共用同一 2D 工作平面**（2026-09-30 第三批）：多面对象时所有面都用「全局参考平面」做 2D 空间（不再各面用自己中心的切平面，那样两张曲面片的方向/相位对不上、看着扭曲）。两处防退化：面几乎垂直于参考平面（|cos|<0.1）时该面退回自己的切平面并写 Note；只有面本身就落在参考平面里时才走平面直投，倾斜面走 ClosestPoint 回投到面上（否则条纹会飞离曲面）。
- **多重曲面按一个整体排版**（2026-09-30 修）：全局基准 = 面积最大的平面面（方向 = 该面坐标系里 AngleDeg 对应的 3D 方向；锚点 = 该面 2D 区域中心）。其它面把全局方向投影到自己的切平面、按同一锚点取**同一族**条纹 → 共面/相切接缝处条纹严丝合缝接上。单面时参考面就是它自己 → 与老版本逐点一致。
- **边距只在外轮廓生效**：顺接的内部接缝（两侧都有面且夹角 < 35°，或接缝自己对自己）不算边界，条纹跨过接缝连成一片；折痕 / 实体棱边 / 外轮廓照常留边距。圆头端在顺接接缝处只要求「端头圆心距缝 ≥ w/2」，圆头正好顶到缝（两段端头接上、不互相压过去）。
- 整圈环绕的面（整圆柱侧面）普通模式铺不开条纹 → 明确提示「裁成一段（例如 120° 弧片）或用贴合边界模式」，不再只说「边距过大」。
- 端部三种模式：圆角 / 平齐 / **完全贴合边界**；硬边可倒「圆角半径」。
- **端部圆角是真曲线**（2026-09-30 修）：曲面路径原来把端头半圆固定采样 28 段输出 `PolylineCurve`（平面上看不出来，曲面上就是 28 段直线）；现在改为解析圆弧段 + 按弦高容差自适应采样的 NURBS（`MakeOutlineCurve`），平面面仍给精确 `ArcCurve`。
- 面板：条纹宽度 / 间距 / 倾斜角度 / 边缘距离 / 圆角半径 / 实时预览 / 贴合边界 / 端部圆角。

### 参数化阵列纹理
- 6 种阵列 × 4 种形状；同心环/螺旋/抖动 可点选圆心；曲面用 UV 参数域 + 网格自适应铺开。
- **多重曲面按一个整体排 · 全局排版（2026-09-30 第三批）**：多面对象先在**整个对象的拟合平面**（`Plane.FitPlaneToPoints`）里铺一套阵列，再把每个候选点投到离它最近的面上成形 —— 整个对象就是一套阵列，接缝两侧是同一个图案的延续；边距只在自由边/折痕处生效（顺接接缝不算边界，图案跨过去）。命中率 <15%（对象太弯）时自动退回下面的「逐面 + 全局相位锚点」并说明原因。
- **多重曲面按一个整体排 · 逐面 + 全局相位锚点**（退回路径）：多面对象自动启用**全局相位锚点**（参考面 = 面积最大的平面面，锚点 = 该面 2D 区域中心），每个面仍按自己的参数域铺，但格点对齐到同一套全局阵列 → 相邻面接缝两侧是同一个阵列的延续（自检：两块共面片所有图形中心离同一套间距格的最大偏差 < 0.15mm）。
- **「选择渐变物件」**（2026-09-30 第三批）：面板顶部与「选择物件」并排，选任意物件当渐变起点（取它包围盒中心）；记的是物件 ID、每次现取中心 → **移动它会实时跟随**（文档事件 + 400ms 轮询，等停下来再重算）；未选红 / 已选绿。
- **「参考面」卡片按需显示**（2026-09-30 第三批）：对象只有 1 个面时整张卡片隐藏（两种设置效果相同，留着占地方）。
- **「参考面」分段控件**（2026-09-30 加）：**选中面** = 只生成命令里点选的那一个面；**全部面**（默认）= 整个多重曲面的所有面；单面对象时置灰并提示「两种设置效果相同」。拾取命令开了子对象选择，点选到哪个面就记哪个面（没点到面时按点击位置最近的面兜底）。

### 泰森多边形纹（本轮大改）
- **只输出曲面网格**：胞元边界线框、边界图层、「胞元边界曲线」开关**已全部删除**（用户要求做减法）。
- **「参考面」选项**（面板分段控件，始终可见）：**选中面** = 只处理命令里点选的那一个面（按外边界收平、不做斜接）；**全部面** = 处理整个多重曲面的所有面（接缝处胞元连续）。对象只有 1 个面时该控件置灰并提示「两种设置效果相同」。
- **「胞元渐变」**（新）：点「选择渐变物件」选一个物件当参考，胞元从它向外**逐渐变化**（正幅度 = 越往外越小，负 = 越大；自动半径取参考点到面最远角）。实现是变密度泊松盘采样（间距按到参考点的距离缩放）+ 过渡宽度按局部胞元尺寸等比缩放；渐变模式下不做 Lloyd（那会把密度重新均匀化）。自检用例 9：幅度 0.6 时靠近参考点一半的胞元平均面积是外侧的 **1.74 倍**，关掉渐变后比值 0.93（对照组）。
- **「胞元输出」选项**（面板分段控件）= 输出拓扑，三项：
  - **整体一张面**：多重曲面合并 + **按「顺接」焊接**成一张连续面（接缝两侧顶点落在同一批公共采样点上、位置完全重合；焊接后接缝上没有裸边）；输入本身是折痕的地方不焊（折痕仍是硬边）；
  - **跨面平滑**（默认）：多重曲面也**合并成一张连续面**，内部接缝做法向混合（对附近所有共享边按距离加权，角点也对称）→ 接缝严丝合缝（实测间隙 0mm）且不留折痕；
  - **每胞元一张面**：每个胞元切成独立对象分开输出，可单独选中 / 上色 / 偏移（同一图层）。
- **整体模式只输出一个对象**（各面网格合并），多重曲面输入得到的就是一张连续面。切分按「网格面中心最近的种子」分组，相邻胞元**共用同一批顶点**，所以切分不丢面、不重叠 —— 自检实测 25 个胞元对象合计 60000 面、总面积与整体模式差 **0%**。
- **跨面连续**：所有面共用一套 3D 种子点云，高度场按 3D 距离算 → 相邻面在接缝两侧算的是同一个连续函数（实测跨面高度差 **0 mm**，改前 2.999）。
- **接缝斜接**：边界点放到「偏移平面的交线」上，角点解「多平面交点」→ 实测接缝 3D 间隙 **0 mm**（改前 4.243）。单面模式不做斜接。
- **接缝公共采样点**（2026-09-30 修）：每条共享边按 step 采样一次（同一条边、同样段数 → 两个面拿到逐位相同的 3D 点），网格点吸附时吸到这批**公共点**而不是各面自己最近的边界点。改前两面顶点互相错开半格（看着就是「两张面拼的」），改后同一条缝上取 61 个参数点，间隙 **0 mm**。
- **删除 vs 移动**（2026-09-30 修）：Rhino 的 Move/Transform 常常是「先删旧对象、再加新对象」，直接按删除事件处理会误报「渐变参考物件已被删除」→ 现在删除事件延迟 250ms 复查一次，对象还在就只当移动/替换（继续跟随，不关渐变）；参考曲面同理。
- **「胞元造型」= 平顶 / 穹顶（鹅卵石）**（2026-09-30 第三批）：穹顶模式高度按 `depth·(到边界距离/(胞元尺寸/2))^穹顶圆度` 算 —— 胞元中间鼓起来、边界平滑收进去（没有沟槽平底、没有平顶），配「穹顶圆度」滑块（0.3–3，越小越饱满）能调出鹅卵石效果；平顶模式与原算法逐字一致。
- **「胞元输出」合并成 4 项（2026-09-30 第七批，用户报「勾了每胞元一个曲面边缘还是锯齿」）**：
  原来「每胞元一张面」在**网格**模式里，而 NURBS 是另一个独立勾选框 —— 名字太像，用户勾的是**网格**那项，
  网格按胞元拆开的边界就是**网格格子**（放大必然台阶）✗。现在合成一个分段控件：
  `整体一张面 / 跨面平滑 / 每胞元·网格 / 每胞元·NURBS`，选中 NURBS 时 `NurbOutput=true`，提示行写明
  「每胞元·网格的边界是网格格子、会有台阶；要光滑边缘选每胞元·NURBS」。
  自检加判据：修剪过的胞元曲面，外环边数必须 ≤12（= 胞元多边形的直边；网格台阶会是几十上百条）。
- **卡死修复（2026-09-30 第六批，用户报「一点就卡死」）**：胞元 NURBS 原来在**每次实时预览重建**时都会全量构建（每胞元 13×13 控制网 + `BrepFace.Split` 修剪），
  胞元一多就是分钟级、界面像死了一样。现在：① **预览一律不建胞元曲面**（内部开关 `WantCellSurfaces`，只有点「生成」那一次由会话置 true）；
  ② 加**时间预算** `CellSurfaceBudgetSec`（默认 12 秒），到点就停并如实报告「已建 N 个、剩余 M 个跳过」；
  ③ 平面面不再做多余 `ClosestPoint`、曲面面只对「胞元内部那一圈」严格回投（外圈用切平面近似）→ 单胞元成本大降。
  自检加了一条回归断言：`WantCellSurfaces=false` 时 `CellSurfaces.Count == 0`。
- **「按胞元输出 NURBS 曲面」（2026-09-30 第五批，用户口径）**：每个细胞 = **一张**平滑 NURBS 曲面（不再是网格转 Brep 的一堆小方块面）；
  细胞之间 **G0**（边界重合：胞元边界处高度为 0，两边在同一圈上接住）；**细胞边缘严格贴合原曲面**（h=0 的采样点回投到面上，不是切平面近似）。
  实现：`CellNurbs.cs` —— 胞元多边形（3D 距离 3×胞元内的邻居做半平面裁剪）→ 13×13 控制网点阵（胞元外 h=0）→ `NurbsSurface.CreateFromPoints` →
  用「曲面自身参数域取点」生成的边界曲线做 `BrepFace.Split` 修剪（按面积最接近多边形的那片当选）→ 每胞元一个 Brep。
  这条路顺带**没有锯齿**（曲面是解析 NURBS，不是网格离散）。修剪失败/退化胞元自动退回未修剪片并计数。
- **「输出多重曲面（NURBS）」旧选项（网格转 Brep，仅当按胞元那套不可用时）**：勾上后自动进入「只保边界重合」的省算模式 ——
  ① 关掉接缝法向混合（公共采样点已保证两侧边界**逐位重合** = G0 足够）；② 采样间距自动放宽到
  `max(原间距, 过渡宽度×0.25, 胞元×0.12)` 并在报告里写明（浮雕特征尺度就是沟槽宽度/胞元尺寸，放宽后网格面数降一个数量级 → 快得多）；
  ③ 转 Brep 后当面数 ≤3000 时合并共面（`MergeCoplanarFaces`）—— **实测只降 1.3~1.5 倍**（网格转出来的面共享边不规整，合不干净），面数更多就跳过并在命令行说明。**结论：这是「多面片多重曲面」不是干净 NURBS**；要真正干净的 NURBS 得按胞元重建（平顶一张修剪平面 + 侧壁），列为后续可做项。
- **「输出多重曲面（NURBS）」选项（原说明）**：勾上后输出 Brep 而不是网格 —— 下游能布尔/倒角；转换失败自动退回网格。**共面合并**：转出来后调 `Brep.MergeCoplanarFaces(0.001)` 把胞元平顶的三角面合成一张平面、每段侧壁合成条带（实测只降 1.3~1.5 倍）。**但**该 API 很慢（4.7 万面上会跑到分钟级、把界面卡住）→ 只在 `Faces.Count <= 8000` 时合并，大网格保持「多面片多重曲面」。**注意**：胞元凹凸是硬边浮雕，无法用「一张 NURBS 曲面」表达；要真正干净的 NURBS 得按胞元重建（每胞元一张修剪平面 + 侧壁），那是另一件事。
- **采样间距的静默放大**（2026-09-30 修，用户报「锯齿」的根因）：节点数超过上限时会把采样间距放大，原来**不报告** —— 用户设 0.1mm 采样 + 2mm 胞元时网格被悄悄放大到 ~1mm，每个胞元只剩两个采样点，表现就是胞元边界一圈明显锯齿。现在：上限提到 **300 万节点**，一旦放大就写进状态条（原间距 → 实际间距 + 怎么调）。
- **渐变跟随物件**（2026-09-30 修）：渐变参考记的是**物件 ID**（不是坐标），每次重算现取包围盒中心；文档事件 + 400ms 轮询兜底（Gumball 拖动不一定发事件，等物件停下来才重算）→ 移动参考物件，预览实时跟着变。
- **边界收平只作用于自由边**（多重曲面内部接缝不再被压平）。
- 种子按面生成后**裁剪到面内** + 跨面去重（重叠区只留一份，避免接缝处密度翻倍）。
- **健壮性**（针对「复杂曲面生成失败/只剩线框」）：比例尺改为在**修剪区域的 uv 范围**内采样（原来是整个定义域平均，参数化不均匀时会严重偏），并加了「2D 周长 vs 3D 实际长度」自检纠正；内外判定加洪泛索引（原来每个节点对全部边界线段做射线求交，长边界会退化成几分钟）；高度场退化时给明确提示。
- 每个面有 `Diag` 字段（阶段数字）写进报告，排查「生成不出」先看它。
- 参数：胞元尺寸 / 凹凸深度 / 过渡宽度 / 凸起形状 / 规整度 / 随机种子 / 边界收平 / 采样间距 / 生成范围 / 实时预览。

### 径向渐变圆点（2026-09-30 新增 · 第 5 个插件）
- **纯参数面板**：不需要选参考面，运行 `RadialDots` 直接开面板；生成在当前视图的**工作平面（CPlane）**原点。
- **按半径渐变**：直径 = f(到中心距离)，带内两端收缩、峰值在「峰值位置」处，两侧按「衰减」指数衰减（峰值位置 0 = 内边缘、1 = 外边缘）。
- **默认值/量程**（用户口径：默认小尺寸、滑杆 0–10、两位小数）：外半径 10（滑杆 0.5–10）/ 内半径 4（0–10）/ 间距 1（0.05–5）/ 最大直径 0.9（0.05–5）/ 最小直径 0（0–5）/ 峰值位置 0.3（0–1）/ 衰减 1（0.1–5）；步长全部 0.01；要更大直接在数字框输入（上限 2000 / 200）。
- **4 种阵列**：同心环（相邻环可错开半格）/ 螺旋（黄金角，面积均匀）/ 方形网格 / 交错网格；**5 种图形**：圆 / 方 / 三角 / 六边 / 圆方交替。
- **重叠自动布尔合并**（默认开，2026-09-30 第五批加固）：外接圆 + 并查集先分组，只对真有交集的组做 `Curve.CreateBooleanUnion`；
  分治叶子降到 40；**收尾清理重写**：多轮（≤6）按真实相交重新分组（48 点双向 `Curve.Contains` 判定）+ 每轮独立复核，
  只有「交叠对数变少（或相同但条数更少）」才采用；布尔失败时按空间对半切递归兜底（两半都保留，宁可多几条不留交叠）；
  诊断（轮数/组大小/布尔失败次数/对半切次数/交叠对数前后对比）写进 `res.Diag`，面板可看。
  根因记录：旧实现里 `UnionRec` 某层布尔失败会静默保留两半，而总周长确实变短 → 外层照样采用 → 输出残留交叠且无提示。
  组内**分治**（空间排序后每批 ≤48 条先并，结果逐层并）—— 实测 958 个圆一次布尔直接失败（合并组 0、输出仍有 1281 对相交），
  分治后正常合并；某组失败会写进面板提示（不假装没重叠）；只有「总周长真的变短」才采用结果（否则说明其实没相交或布尔失败）→ 有交集的并成一个整体，没交集的保持独立个体。
- 输出到「径向渐变圆点」图层；预览画的就是合并后的最终形态。

### 网格修复（2026-10-08 新增 · 第 6 个插件 · **无面板，一键工具**）
- **解决什么**：复杂修剪曲面（外环 1 + 内环 43、约 1000 条修剪边这类）在「快速」网格预设下
  —— 该预设的「最大长宽比」`MeshingParameters.GridAspectRatio` = 0 —— 网格器返回**退化网格**
  （实测 3 顶点 / 1 面、面积 ≈ 2.76e-08），于是着色 / 渲染 / Ghosted 模式下面体不显示、只剩边缘线。
- **修法（三步，缺一不可 —— 用户实测「点了还是不可见」后逐条定位出来的）**：
  1. 把**物件级**自定义渲染网格参数的「最大长宽比」由 0 改成 6，**写完必须读回复核**
     （踩过：写失败也当成功，读回还是 0，后面全是白干）；参数随 3dm 保存（文档级网格设置保存后不保留）。
     实现细节：用 `CloneWithAspect()` 从有效参数**新建一份 `MeshingParameters`** 再改，别直接改
     `GetRenderMeshParameters()` 返回的实例再赋回去（那条路读回仍是 0）；写不进去时先 `CustomMeshingParameters = null`
     清空再写。
  2. **清掉旧网格缓存**（命令 `_ClearAllMeshes`，RhinoCommon 没有公开 API）：不清缓存，显示管线会一直用
     旧的退化网格 —— 只做第 1、3 步时面体照样不显示（实测着色面体像素 = 0）。
  3. 用**写进去的那份参数**重建渲染网格（不要重新 GetRenderMeshParameters 再改）。
- **实测验收**（真实 11.3dm 几何 + Rendered 视图 + `_-ViewCaptureToFile` 真渲染截图，
  判据 = 浅中性灰着色面体像素）：修复前 **0** → 修复后 **24335**（整片面体着色显示）；
  网格数据侧：1 面 → **24066 面**；再跑一次幂等（退化 0 / 修复 0）。
- **用法**：工具条上就一个图标，点一下即修复 —— 有选中物件就修选中的，**没选中就扫描整份文件**里渲染网格退化的物件；
  全程无面板、无命令行提问。健康的物件一概不动，跑完给一行汇总。
- **Rhino 7 差异**：Rhino 7 的 RhinoCommon **没有**物件级自定义网格参数（8.0 才开放；7 只有文档级
  `RhinoDoc.SetCustomMeshingParameters`），所以 net48 构建走等价路径：用「最大长宽比 6」的参数直接重建渲染网格
  并存入物件，命令行会写明走的是这条路径。
- 只读打开用户 3dm 做自检（复制到 `%TEMP%` 再 `RhinoDoc.OpenHeadless`），**绝不写回原文件**。
- 根因分析的原始诊断资产在 `D:\rhino_diag\`（`diag10.py` + `report10.txt` = 最终结论：`good_mp()` 12 参数配方 + `_ClearAllMeshes`；
  `fix_mesh_aspect.py` = 一键修复脚本；`proof_fixed.png` / `fix2_reopened_rendered_2.png` = 成功后的渲染证据）。再看这个插件的问题先读这三样。

## 10. 「每胞元一张面」的现状与后续（2026-09-30 第三轮）

用户口径：**输出拓扑**（不是「参考物件有几个面」）——「每个胞元各自成为一张独立曲面，再拼成多重曲面；输入是单个曲面 / 物件 / 多重曲面都支持」。

已做（`PerCell`）：
- 网格按胞元切分，**每个胞元一个独立网格对象**，同一图层；相邻胞元共用顶点，边界严丝合缝（自检用例 8 断言：面数一致、总面积差 0%）。
- 面板「胞元输出」三项：**整体一张面**（各面各自成片、保留输入折痕）/ **跨面平滑**（默认，多重曲面合并成一张连续面）/ **每胞元一张面**。
- **整体模式只写一个对象**（各面网格 `Mesh.Append` 合并），所以多重曲面输入得到的是一张连续面。

**关于 NURBS 版（用户已明确选择网格版，这条留作以后备选）**：用户口径是「每个胞元各自成为一张独立曲面，再拼成多重曲面」。
现在的实现是**网格**（每胞元一个独立网格对象，同一图层，可单独选中/上色/偏移）。如果以后要做成 **Brep 多重曲面**（Rhino 里「曲面/多重曲面」是 NURBS 术语），需要曲面拟合，推荐做法：
对整片高度场拟合一张 NURBS 面，再用胞元边界曲线切成 N 个修剪面（接缝天然对齐）；风险是沟槽底是折痕、光滑拟合会略微倒圆，且胞元内部分辨率低于网格。

### 几何口径（做出来的到底是什么）
1. 边界：平面曲面/平面 Brep（取面积最大的平面面的外轮廓）或**闭合平面曲线**；多选逐个处理；弯曲面明确拒绝（「没有平面面（弯曲面不支持）」）。
2. 轮廓按「面片大小」等距采样成环 → 环就是**面片的外轮廓**（曲线边界是按弦近似，所以圆边界出来的面积比 πr² 略小 ~0.6%，属正常）。
3. 内部撒点：**抖动网格**（网格边长 = 面片大小，±0.5 格抖动），离边界 < 0.45×面片大小 的点丢弃。
4. 三角剖分：**Rhino 原生 `Mesh.CreateFromTessellation`（不给轮廓）+ 重心落在边界内才保留**。
5. 松弛（可调 0–20 次）：把互相靠得太近的点**推开**（边界环点当固定源），用抖动网格格子做邻域，O(n)。**不要用「向邻居平均靠拢」**——那会让整片点往中间收缩、边界一圈反而变大三角（实测 CV 从 0.52 涨到 1.27，等于变差）。
6. 高度：顶点沿边界平面法向随机 ±起伏高度；高度按**平面坐标哈希**取值（同位置永远同高度）→ 共享顶点天然不裂开，网格顶点数 < 3×三角面数（焊接后）。
7. 「固定边界」= 边界上的点（到边界环距离 < 容差）高度锁 0；关掉则边界点也起伏。
8. 输出：线框 = 三角网格全部拓扑边（`MeshTopologyEdges.EdgeLine`）→ `LineCurve`，进图层「钻石切面-线框」；面 = 每个三角面一张 `Brep.CreateTrimmedPlane(平面, 三角闭合曲线)`（单面、平面、NURBS 修剪平面），进图层「钻石切面-面」。面法向统一朝边界平面法向。

### 关键结论（别踩）
1. **`Mesh.CreateFromTessellation` 的 `outlines` 参数不生效**（Rhino 7.0.20314 / 8.30.26103 都一样）：只要传非空轮廓环，返回的网格就是「有顶点、0 个面」（实测 A/B/C/D/H 五种组合全 0 面）；不传轮廓时给的凸包 Delaunay 是准的（100×100 点集 → 面积正好 10000）。所以正确用法 = **轮廓点也放进点集 + 重心剔除边界外的三角面**，不要指望 outlines 做约束。
2. **自实现 Bowyer–Watson 兜底要加两道保险**，否则在「一堆点共圆」的退化点集上会炸：① 插入顺序确定性打乱；② 外接圆判定用**相对容差**（`|det| ≤ scale×1e-12` 当圆外）。加之前圆边界实测 120 点出 2231 个三角面（上限 235）、面积 70 倍；加之后 218 面、面积差 9%。
3. **兜底结果要面积复核**：兜底剖分出来的面积与边界面积差 > 5% 就**明确拒绝**（报「自实现剖分结果不可信」），宁可不出几何也不给错几何。自检里圆周强制兜底那一项就按「要么 <5% 要么明确拒绝」断言。
4. **`MeshTopologyEdgeList` 没有 `GetTopologyEdge`**（Rhino 7 探针确认）：要边就用 `EdgeLine(i)`。
5. **`Curve.ClosestPoint(Point3d, out double)` 只返回参数**，没有返回 `Point3d` 的重载 —— 要「最近点」自己 `PointAt(t)`；3D→平面 2D 直接用平面轴点乘（`To2d`），别绕 ClosestPoint。
6. **面片大小给得太小会点数爆炸**：内部点数上限 `MaxInteriorCells = 8000`，超了自动放大网格并在面板/报告里如实写「面片大小太小：点数上限 8000，网格已自动放大到 X」。没这个上限时 0.0005 的面片大小实测跑 366 秒、40 万个三角面。
7. **固定边界的判定用「到边界环的距离」**，不要用「到密集轮廓多边形的距离」：曲线边界的密集多边形与采样环不是同一条线（弦差），会把边界点误判成内部点、固定边界失效。
8. **自检里判断「顶点在不在边界上」要先把点投到边界平面再比**：固定边界关掉时边界顶点已经起伏（3D 上离曲线远了），直接比 3D 距离会一个都匹配不上（表现为「OFF 时最大高度 0」的假失败）。
9. **`Mesh.IsValid` 是属性不是方法**（`r.Shaded.IsValid`），`Curve.DivideByCount(int,bool,out Point3d[])` 返回 `double[]`（参数数组）不是 bool。

### 2026-10-09 第六轮（用户口径：网格模式重做 —— 每个三角切面一张网格片，再在片内细分）
用户实测：「线框模式没问题 但是网格模式问题很大 … 我要求你把每一个三角形生成单一的网格片 然后再这个基础上细分网格 你现在的拓扑结构完全不对」。
上一轮「整张三角网合成一个多重曲面再丢给 QuadRemesh」的做法作废：QuadRemesh 会**重构拓扑**（出四边面 + 转 SubD 圆滑），切面棱线全丢，
预览里就是一团对不上线框的网格。**新管线**（`DiamondFacetCore.BuildFacetMeshPatches`）：
1. 数据源 = `res.Shaded`（贴过边界、带高度的切面三角网），**每个三角面 = 一张独立网格片**
   （`AddPatch`：重心格点 `v(i,j)`（i+j≤n）拆成 n×n 张三角面，绕向沿用源面 → 法向不翻）；
2. 细分点**全部由该片 3 个角点线性插值** → 片内保持平面（钻石棱线原样保留）；面积守恒实测差 0%（2423.73 vs 2423.73）；
3. 相邻片共享边上的细分点由同一段端点插值 → 位置重合；`Vid` 用整数键（容差 = 包围盒对角线 ×1e-9）把同坐标顶点合并成**一张网格**，
   所以没有裂缝；两片档位不同时共享边上会出现 T 形点（几何上仍共线，看不到缝）；
4. 档位分配：取每片最长边 `r_i`，`beta = (平滑度-50)/50`（100% → 1），`m0 = sqrt(目标面数 / Σ r_i^(2β))`，`n_i = round(m0 · r_i^β)`（限 1~64）。
   **平滑度 100% = 档位按边长配平（网格边长一致）；80% = 大面更粗**。实测（圆 R40 / 面片 10 / 目标 5000）：

## 15. 流程优化（2026-10-09 第二轮，用户口径：「测试的时间有点过长了」）

### 时间账（都是实测，不是估计）

**跑法（2026-10-09 用户口径：「反复弹犀牛很影响干活」）**：Rhino 8 **没有真正的无头模式** —— 插件命令必须在 GUI 进程里跑，
没有 `-headless`/`Rhino.Compute` 这条适用于任意插件命令的路。可行且已验证的做法是**隐藏窗口启动**
（`Start-Process -WindowStyle Hidden`）：进程照常加载插件、跑几何与面板自检，但**屏幕上完全看不到、不抢焦点**。
`run-native-selftests.ps1` 现在**默认就是隐藏窗口**；唯一的例外是 MeshFix 用例6「显示可见性」（要真渲染截图
`_-ViewCaptureToFile`），隐藏下会如实 SKIP（报告写「本窗口拍不到真渲染…不是修复失败」），期望值自动按
`PassWith - HiddenDelta` 算（MeshFix 15 → 14，0 失败）。
**只有要这条显示证据时才显式弹窗**：`pwsh -File run-native-selftests.ps1 -Visible -Only MeshFix`（约 15 秒，弹一个窗口）。

| 环节 | 旧做法 | 实测耗时 | 优化后 |
|---|---|---|---|
| 全量自检回归 | `run-native-selftests.ps1` 逐项跑，**期望值过期就 throw 中断** | 每轮 ~8 分钟（刚构建完的冷跑，含杀软扫描新 .rhp）；本轮因 Voronoi(76→74)/Halftone(25→23) 期望过期，**白跑 2 轮 ≈ 15 分钟** | ① 期望值随「用户 3dm 文件是否存在」自动选（`PassWith`/`PassWithout`）；② 单项不符**不再中断**，跑完给汇总表 + 每项用时；③ 迭代期用 `-Only <名字>`（单插件 15~60 秒）。优化后实测 **7 项 ALL-PASS：可见窗口 186 秒 / 隐藏窗口 143 秒**（热跑；冷跑仍 ~8 分钟，主要是杀软扫描新构建的程序集）。**一轮拿全，不再重跑** |
| 静默安装 + 交付核对 | 手工：先 `Start-Process` 跑 /silent、再逐个查注册表/payload/RUI/进程 | 本轮排查约 15 分钟（含 8 分钟假死误判） | 一条命令 `pwsh -File install-and-verify.ps1`：Rhino 在跑就**直接说清楚**（`/silent` 会 exit 2 中止，不用再去查进程/窗口/注册表）；装完自动断言日志 7 注册 + RUI 7 按钮 + payload↔已安装 7/7 + 注册表 7/7。**约 1~5 秒**（`-SkipInstall` 只核对 ≈1 秒） |
| 安装器为什么「假死」 | —— | 8 分钟无输出 + 文件时间戳混乱 | 真相：**Rhino 在跑时 `/silent` 立即 `exit 2` 中止**（0.3 秒），进程却仍留在任务管理器里让人以为在跑；Rhino 关掉后整装只要 **0.3~5 秒**。另外 **bash 沙箱的 C: 视图会给出过期/混合的文件时间戳** —— 判断安装状态一律用 `install-and-verify.ps1`，别用 bash `ls` |

| 方向散布 | 方向随机范围 | **条带摆动幅度**（低频横波） | **环的起伏**（3θ 角向谐波） |
| 波长 / 波高 / 波峰形状 / 随机种子 | 三种通用；**种子给相位**（所以条带/同心下「换一种」也有反应） | | |

6. **固定边界**（勾选框）：边界顶点**硬锁**（位移 = 0）+ 从边界向内过渡（`过渡宽度` mm，给 0 用 `波长×0.5` 兜底；`过渡平滑度` 0 线性 → 0.5 smoothstep → 1 smootherstep，见 `BlendCurve`）。不勾 = 全幅到边（参考图 1/2 的口径）。拖过渡参数会**自动勾上固定边界**（否则它们没作用）。闭合体（没有开放边界）时按全幅并在报告里写明。
7. **一键平滑 → SubD + 边界保形**：`SubD.CreateFromMesh` 后，固定边界时把**边界边打 `SubDEdgeTag.Crease`**、**边界顶点打 `SubDVertexTag.Corner`**，再 `UpdateAllTagsAndSectorCoefficients()`。不做这步 Catmull-Clark 极限面会把边界往里收、四个角磨圆（用户实测：「一键平滑成 SubD 之后 边界就没有固定到 4 个节点上了」）。实测 120×60：打 crease 后极限面包围盒 **= 120×60**、角点到极限面距离 **0**；不打 crease 角明显被磨掉。

### 关键结论（别踩）
1. **Rhino 7 / 8 的 SubD API 不一样**：Rhino 7 没有 `SubDVertex.Tag` / `SubDVertexList.SetVertexTags`（角点标记是 8 才有的）；`SubD.ToBrep()` 在 7 里必须传 `SubDToBrepOptions`、没有无参重载 → 相关代码一律 `#if !RH7` 隔开（两套 TFM 都要能编过）。
2. **`SubDVertexList` 既不能 foreach 也不能索引**（Rhino 8 实测）：顶点要经 `SubDEdge.VertexFrom / VertexTo` 取，再用 `SetVertexTags(IEnumerable<SubDVertex>, tag)` 批量打标；`SubDEdgeList` 可以 foreach ✓。`SubDEdge.Tag` 两代都有 ✓。
3. **「接线测试」是本轮最有价值的方法**：面板加 `SetParam(行名, 值)` / `ParamEnabled(行名)` 自检钩子，用例里**逐参数在面板上改值 → 生成 → 网格特征值必须变**（3 波形 × 10 参数 = 30 项）。第一次跑出 25 条失败，查出是钩子的行匹配写错（标签 Top=y+6、数字框 Top=y+2，**差 4px**）；修好后立刻暴露两个真问题：随机种子在条带/同心下完全没用、波数在条带下只有 1↔2 有区别。
4. **过渡类参数要量「过渡带内」的幅度**：整体最大 |Z| 由内部全幅顶点主导，量它看不出过渡宽度/平滑度的差别（实测 1.849 vs 1.849 假通过）→ 用 `BandAbsZ(mesh, lo, hi)` 只统计离边界 lo~hi 的顶点；且平滑度只在 **t<0.5 半段**单调（smootherstep 在后半段反而比线性大）。
5. `Plane.ClosestPoint(Point3d)` 返回的是**平面上的 3D 点**（不是 2D 坐标）→ 要 2D 自己用平面轴点乘（`To2d`）。
6. `Mesh.Normals.ComputeFaceNormals()` 不存在（面法向在 `mesh.FaceNormals`）；`Brep` 没有 `IsPlanar`（用 `BrepFace.TryGetPlane`，或拟合平面 + 平面度判定）。
7. 3 点闭合折线**必然共面**（「非平面曲线」用例要用 ≥4 点且不共面），否则用例自己写错。

## 18. 第 9 个插件「多重曲面转单一曲面 SurfaceUnify」（2026-10-10 第二轮）

用户口径：把各种复杂的多重曲面全部转成**单一的开放式曲面**，边界完全逼近原多重曲面、内部尽可能拟合原曲面；随后用户给了实测文件 `D:\UserData\Desktop\2234.3dm` 验证贴合情况，并另报「插件 8 的同心涟漪不是圆是椭圆」+「unify 图标不好看、和别的插件不像」。

### 算法（自研，无第三方依赖）
1. 输入：Brep（曲面 / 多重曲面 / 挤出体）或 Mesh；曲线 / 细分物件 / 点明确拒绝；闭合体（无裸边）拒绝并说明原因。
2. 片状网格：Mesh 输入先 `Duplicate()` 再 `Weld`（**绝不动用户文档里的几何**）；Brep 输入按 diag/60 网格化后 `Weld`（不焊接 → 多重曲面的内部接缝会被 `GetNakedEdges` 当成边界）。
3. 裸边环 → 外环（鞋带面积最大）+ 内孔候选；拟合平面 + 主轴坐标系；外环取 4 角 = **对角极值**（矩形取到真角点），去重 + 每段弧长 ≥5% 周长校验，不合格退化成弧长四等分。
4. 4 条边按弧长等分采样 → **3D 双线性 Coons 基面**：边界点 = 原边界采样点 → 边界天然完全逼近；Brep 输入再把边界点吸附回真实边（消掉网格弦差）。
5. 贴合：**先沿基面法向打射线**（`Intersection.MeshRay`，±法向取最近命中；命中点用 `Brep.ClosestPoint` 精修到精确曲面），射线打不到再退回最近点。**这是凹袋 / 兜形 / 槽形壳体能不能贴合的关键**。
6. 拉普拉斯光顺（边界保形 = 边界点不参与）→ `NurbsSurface.CreateThroughPoints(flat, nu, nv, 3, 3, false, false)` 插值出单一 NURBS 面。
7. 内孔：孔环投影到结果面（`ClosestPoint` → 曲面上的点 → `PolylineCurve`）→ `BrepFace.Split` → 取面积最大的那块（带孔那片）。
8. 偏差：结果面 25×25 采样 → 到原曲面 / 网格的最近距离（最大 + RMS）；**孔洞区域不参与统计**（那里没材料）；测量用自己宽容差（≥ 对角线一半），不受面板「最大贴合距离」影响。报告里给最大 / 平均 / 边界偏差 + 面积比 + 未贴合点数 + 折叠单元数。
9. 预览 = 输出：结果面着色 + 线框，原边界画红线对比；写文档到图层「单一曲面」，对象名带偏差。

### 本轮踩的坑（都已修）
1. **`NurbsSurface.CreateThroughPoints` 参数顺序是 `(points, uCount, vCount, uDegree, vDegree, uClosed, vClosed)`** —— count 在前、degree 在后；传反直接返回 null（XML 的 `<param>` 顺序就是实参顺序）。点序 = u 慢变（`points[i*vCount+j]`），用四角校验 `CornersMatch` 兜底。
2. `BoundingBox.Diagonal` 是 **Vector3d**（要 `.Length`）；`Point3d − Point3d` = Vector3d，所以 `a + b − c` 会算成 Vector3d → 逐分量写。
3. `BrepFace.Split(IEnumerable<Curve>, double)` 返回 **Brep**（内含多张面），不是 `Brep[]`；取单面用 `BrepFace.DuplicateFace(false)`。
4. `File3dmObjectTable.Add` 在 **Rhino 7 只有 `Add(File3dmObject)`**（2 参重载是 Rhino 8 才有）→ 自检里改成只读报数，另存走 Probe 命令的 `RhinoDoc.WriteFile`。
5. **Coons 基面的法向朝向由边界环走向决定、可能是反的** → 必须与壳体平均顶点法向对齐，否则「法向一致」守卫会把所有射线命中判成「贴到背面」全拒（实测碗形 140 点全被拒）。
6. **只找最近点会给凹袋扣一个「盖子」**：实测面积比 0.155 / 最大偏差 11.1% → 改成射线贴合 + 自动贴合范围 0.25→**0.75 对角线**后，碗形用例偏差 8.8→0.21、面积比 0.69→0.99。
7. 自检里比较「两个参数结果是否不同」用的**几何签名权重必须不可分离**：可分离权重（如 `1+0.001x+0.002y`）下，一整周期正弦起伏在对称采样点上正负相消 → 平坦面与波浪面算出同一个签名（假通过）→ 改用含 `x·y` 与 `z²` 交叉项的权重。
8. 编译偶发 `0xC0000005`（access violation，随机落在不同项目）→ `native-gate.py build-panels` 遇错即停，改成逐个构建 + 重试 3 次。
9. 水波纹自检原来把同心涟漪写成「椭圆环」并断言轴对称 → 用户实测反馈「不是圆是椭圆」；改成**正圆**：等距点高度必须完全相同（最差差 < 1e-12）；主方向改为「涟漪源偏移方向」，**0° = 源居中**（`mag = 0.25·(1−cos a)·λ`，0° 时偏移恰好为 0），角度越大源越靠外。
10. 图标：第一版（透镜 + iso 线）被用户判「不好看、和别的插件不像」，子代理第二版（透视桶状）读起来像垃圾桶 → 最终版 = **一张带 S 形曲边的整片曲面（透视收分 + 两条 iso 肋线 + 白高光）**，与家族（渐变填充 + 深色描边）一致；kind `unify`，强调色玫红 `#A8456F`。
